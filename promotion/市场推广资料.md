# Move Up · 市场推广资料

核对日期：2026-11-18。主仓库：https://github.com/dongsheng123132/dsh-move-up

## 一句话介绍

Move Up 是 DeepSeek Harness 的免费开源插件：在工作区「…」菜单点击「移到最上面」，就能把这个工作区移到侧栏第一位。

English: Move Up adds one action to the DeepSeek Harness workspace menu: move the selected workspace to the top of the sidebar.

## 给市场提交的简短介绍

工作区太多时，不必拖动很长一段：打开工作区菜单，点击「移到最上面」，一次调整顺序。之后仍可自由拖动。免费开源，npm 包名 `dsh-move-up`。

菜单文字提供中文、英文、日文、西班牙文、法文、德文、俄文、葡萄牙文，并按浏览器语言选择；未覆盖的语言回退英文。DSH 界面手动切换语言时，插件文字不一定同步。

安装：在 DSH 桌面版的插件管理器添加 `dsh-move-up`。此前安装过同功能旧插件的用户，请先停用旧实现，以免出现重复菜单。
